# Análise de Renda Média -Guimarães vs Região Norte 2023
> Projeto prático  do dia 1 estudando Python para Data Analytics.
## Objetivo
Comparar o ganho médio mensal de Guimarães com outros concelhos da região Norte e Lisboa, identificando posição relativa e desigualdade salarial.
## Principais Insights
1. **Guimarães** 1.247€/mês, posição intermediária no ranking.
2. **Desigualdade regional** : Desvio padrão de ~200€ entre concelhos analisados.
3. **Amplitude salarial** : 598€ de diferença entre o maior (Lisboa) e menor (Fafe) valor.
4. **Nota** : Os dados utilizados são fictícios para estudo/treino.
